How a report is placed

  1. Count each report once: the export pages overlap, so the same id can appear twice.
  2. If the desk read it as a one-day move (desk-notes.json), it goes to #3.
  3. Otherwise ask the tenant, not the reporter’s browser (causes.ts): a day-first tenant on a booking-v3 form goes to #2; every other day-first report goes to #1.

Intake’s tag is not used. It is a guess from the reporter’s browser and often names the wrong cause: compare the “tagged as” column in the tables above.

For the desk

  • Merge into a ticket only reports with the same problem, not the same subject.
  • When a new date report comes in, place it with the steps above and merge it into that ticket.
  • Do not close the date reports when the parser fix ships; #2 and #3 need their own fixes.
